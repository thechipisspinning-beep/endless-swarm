# Endless Swarm

Godot 4 prototype of a Mob Control-style game with continuous runs and post-boss perk selection.

## Concept

- 3D almost top-down view
- Swarm of units that walk forward through gates (multipliers, dividers, +N, -N)
- Hazards on the path (spikes, flying axes, etc.)
- Simple bosses
- After each boss → choose 1 of 3 random perks
- Meta progression: unlock up to 5 starting units + unit rarities

## Current Status

Prototype in early development.

## How to run

1. Open the project with **Godot 4.3+** (or latest 4.x)
2. Open `project.godot`
3. Press F5 / Play
